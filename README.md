# CircleAssist

**Voice and AI, right where you work on your Mac.**

Select something on your screen, dictate into a text field, or ask for help with a task. CircleAssist brings these workflows together on Apple Silicon Macs, with local speech recognition and your choice of AI model.

## Work with what is on your screen

Select screen content to translate, explain, or summarize it. Copy the result or keep asking questions in the conversation.

## Speak where you write

Start voice input in a focused, editable text field. Optional AI refinement helps clean up recognized text before you continue writing.

## Ask for help with a task

Use voice or text for web research, reminders, supported app controls, and desktop actions. The HUD shows progress while a task runs.

Clipboard history, saved knowledge, memory management, and MCP tool connections support longer workflows.

## Get started

1. **Sign in to CircleAssist.** Install the app, then use your email verification code to sign in or register and confirm access.
2. **Set up speech.** Download the local speech recognition model, approximately 539 MB.
3. **Choose your AI.** Configure a compatible cloud provider or a supported local model.

Grant macOS permissions when you use the features that need them. Local AI models may require more memory than the 16 GB device baseline.

## Models and costs

Speech recognition runs on your Mac after the speech model is installed. AI tasks use the model you configure. Cloud provider fees are separate from the app's launch offer, and desktop tasks can involve multiple model calls.

When proactive suggestions are enabled, qualifying reminders can also trigger background model requests. You can turn proactive suggestions off in settings.

See the [website](https://quanzhu.fangtangtech.com/en) for current access terms and the [FAQ](docs/FAQ.md) for setup and usage questions.

## Privacy and compatibility

Cloud AI requests send task text and relevant images to your selected provider. If cloud AI refinement is enabled for voice input, the recognized text is sent to that provider too.

Screen capture and desktop interaction need the relevant macOS permissions. Input fields and desktop actions vary by application; image tasks require a model that supports images. Account services, initial downloads, web searches, and cloud AI require internet access.
